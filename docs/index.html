What it does

One pass. Three readings. No guesswork.

SpeedX runs three measurements in sequence and gives every number a definition. Nothing is inferred from a single request.

01 / Latency

Latency first

Ten round trips, then jitter and packet loss. Ping is measured before the connection is saturated, so the reading is not distorted by the test itself.

02 / Throughput

Throughput that adapts

Four download streams and three upload streams run in parallel. Chunk sizes follow the measured rate, so slow links finish and fast links are not held back by round trips.

03 / Share

A result you can send

Each completed test can be saved as a compact result page with a copy-link action. No account, no dashboard, no sign-in.

04 / Privacy

Quiet by default

No ads, cookies, or analytics. Result pages are marked noindex. The app stores the measurements, not your identity.

Method

Measured, then explained.

SpeedX runs three measurements between this browser and the server that delivered the page. A full test takes about 16 seconds.

Full method on GitHub
  1. 01

    Ping

    10 round trips

    The browser times ten requests to the server. The average round trip becomes the ping reading; jitter is the average change between consecutive samples; failed requests count as packet loss.

  2. 02

    Download

    8 seconds · 4 streams

    Four parallel requests pull pre-generated, incompressible chunks from the server. Bytes are counted as they arrive, and the chunk size grows with the measured rate.

  3. 03

    Upload

    8 seconds · 3 streams

    The browser sends generated data to the server, which reads and discards it. As with download, the payload size follows the measured rate.

Reading the numbers

Ping
The average round-trip time across ten attempts, including request overhead.
Jitter
The average change between consecutive samples. Lower is steadier.
Packet loss
The share of the ten pings that did not come back.
Download / upload
The average rate over each eight-second phase, not the peak.

A browser test measures one path to one server, not the rate on your plan. Run it more than once before drawing a conclusion.

Result

The whole reading, in one link.

A completed test can be saved and shared as a compact result page. The link is the result; there is no account behind it.

  • Download, upload, ping, jitter, and packet loss
  • ISP, approximate city and country, server, and timestamp
  • Copy link or use the share sheet

Result pages are marked noindex. Anyone with the link can open one.

Privacy

Keep the reading. Drop the identity.

A result only needs enough context to be useful. It does not need to know who ran it.

+ Stored with a result

  • Download, upload, ping, jitter, and packet loss
  • ISP, approximate city, and country
  • Server name and timestamp

− Never stored with a result

  • IP address
  • Name or account
  • Cookies or analytics

The IP lookup runs when the page loads, but the connecting IP is not saved with the result. ISP and city come from a third-party lookup of that IP.

A shared result is readable by anyone who has the link. It is marked noindex so search engines are asked not to list it.
